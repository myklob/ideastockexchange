# Templates

Every page template of the Idea Stock Exchange, in one place. Each is a self-contained wiki page generated from the HTML file under `templates/` in the repository, which is the copy the code follows and the copy `tools/check_templates.py` keeps current. To change a template, change the HTML; this index and every page under it are regenerated by `tools/wiki_templates.py`, and CI refuses a stale copy.

A page is organised by kind. A **page template** is the shape of one kind of page on the site (a belief, a topic, a work, a linkage, an interest, a stakeholder). An **index template** lists pages of one kind. A **special analysis** is a belief page specialised to one recurring question. An **explainer** argues for a part of the layout. A **retired** template stays only so old links do not break, and says where its content went.

## Kinds of page with no template yet

The page/edge model gives every row its own page. Four kinds have no template file: a **claim** page (a reason or finding argued on its own), an **importance** page ("X is the most important issue for determining the strength of Y"), a **uniqueness** page (how much of a row is already said by another), and a **driver** page. Each is a belief page in the small; `tools/static-site/build_pages.py` builds their claims by formula. A template for each belongs here once written.
