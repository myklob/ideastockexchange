🔍 Argument Trees

Each argument is a belief with its own page. Scores are recursive: Argument Score × Linkage × Importance = Impact. Pro and con impacts sum to the Net Belief Score. A true-but-irrelevant argument scores high on truth and near zero on linkage, so it contributes nothing. Confirmed fallacy claims feed these factors too: a community-confirmed fallacy damages exactly the factor its type targets (relevance fallacies hit Linkage, formal fallacies hit the validity component of the Argument Score, evidence fallacies hit Evidence Quality) and is noted inline in the argument cell. A fallacy accusation that has not been confirmed changes nothing.

🎯 Objective Criteria

These are the measurements that would settle this debate if both sides committed to them in advance. Pick the standard first, then check the result: that is what keeps the verdict tied to the world instead of to whoever argues loudest. The best criteria are specific enough that supporters and opponents would predict different readings. A criterion both sides expect to come out the same way tests nothing. ⚖ Cost-Benefit Analysis

Every cost and benefit is itself a debatable claim with its own argument tree, and every row must survive three questions: compared to what, measured in what units, and how likely? Magnitude is an estimate in explicit units. Likelihood is computed from how that claim’s pro and con arguments score, never assigned by gut. Expected Value = Magnitude × Likelihood. Keep unlike categories (dollars, life-years, people-hours, freedom) in separate rows and subtotal only within a category; converting across categories is itself a debatable claim, so if you do it, state the conversion out loud (e.g., the value of a statistical life). Method per the canonical cost-benefit analysis page and Sunstein’s The Cost-Benefit Revolution.

🤝 Conflict Resolution Framework

Both sides of most debates share the same values. They disagree about how to rank them, and that ranking shifts based on perceived costs, benefits, and likelihood of success.
